QQDeBreath 1.20 Windows 与 macOS 安装使用说明
==============================================

一、Windows VST3 安装

1. 完全关闭 Cubase、Nuendo、REAPER、Studio One 或其他 DAW。
2. 将 QQDeBreath.vst3 文件夹复制到：
   C:\Program Files\Common Files\VST3\
3. 重新打开 DAW，并在插件管理器中重新扫描或重新激活 QQDeBreath。

二、macOS VST3 安装

将 QQDeBreath.vst3 复制到：

/Library/Audio/Plug-Ins/VST3/

三、macOS AU / ARA 安装

将 QQDeBreath.component 复制到：

/Library/Audio/Plug-Ins/Components/

Logic Pro 不加载 VST3。使用 AU / ARA 版本时，将 QQDeBreath 放入第一个 Audio Effect 插槽。

四、首次启动安全提示

如果 macOS 阻止插件，请打开“系统设置 -> 隐私与安全性”，找到 QQDeBreath 的提示并点击“仍要打开”，然后重新扫描插件。

五、ARA 工程重开说明

1. 关闭工程并重新打开后，插件会自动在后台准备当前工程的 ARA 音频缓存。
2. 不需要再次打开或重新进入 ARA 界面来修复播放声音。
3. 缓存准备完成前可能短暂没有声音；准备完成后会自动恢复播放。
4. 分析、区域、监听、Fade、Norm、Gain、EQ 和三轨导出逻辑没有改变。
